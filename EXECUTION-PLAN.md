## Phase 4: Operations & Fulfillment

### 4.1 Customer Intake Flow

1. **Purchase** → Stripe checkout
2. **Intake Form** (auto-sent):
   - What platform? (Mac/Linux/VPS)
   - What messaging apps? (Telegram/Discord/Slack/etc.)
   - What do you want to automate? (helps with skill setup)
   - SSH access details OR we help set up VPS
3. **Gizmo reviews intake** → Flags any issues
4. **Installation** → Gizmo executes via SSH/remote
5. **Verification** → Test all integrations
6. **Handoff** → Email with instructions + video walkthrough
7. **Follow-up** → Day 3 check-in, ask for testimonial

### 4.2 Fulfillment SLA

| Package | Turnaround |
|---------|------------|
| Basic | 24-48 hours |
| Pro | 24 hours |
| Premium | Same-day priority |

### 4.3 Support Model

- **Basic:** Email support only, 48-hour response
- **Pro/Premium:** 30-day priority support, 24-hour response
- **Maintenance retainer:** Ongoing support + updates

### 4.4 Upsell Path


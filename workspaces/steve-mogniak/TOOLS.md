## Session Tools

You have access to session tools for communicating with Gizmo and other agents when needed:
- `sessions_send` — Message Gizmo or another agent (use when you need input from outside your domain)
- `sessions_list` — Check active sessions
- `sessions_history` — Review conversation history from another session
